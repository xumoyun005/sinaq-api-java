# IntelliJ live templates — Sinaq API

1. **Settings → Editor → Live Templates**
2. Click **Import** (or copy templates from `Sinaq_API.xml` into a new group “Sinaq API”)
3. Abbreviations:
   - `sinaq-client` — build `ApiClient`
   - `sinaq-get` — GET + `expectStatus`
   - `sinaq-post-json` — POST + bearer + body + asserts
   - `sinaq-extract` — extract JSONPath value

File: [Sinaq_API.xml](Sinaq_API.xml)
