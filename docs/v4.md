# Sinaq API V4 (0.4.0)

V4 completes deferred V3 items: OAuth password/refresh grants, WireMock stubs,
OpenAPI validation, messaging, distributed execution, response cache, replay,
richer reports, and 500-parallel CI gate.

## What's new

| Feature | Package / module |
|---------|------------------|
| OAuth password + refresh_token | `sinaq-api-oauth` |
| WireMock stub server | `sinaq-api-wiremock` |
| OpenAPI 3 validation | `sinaq-api-openapi` |
| Response cache | `ResponseCache`, `cacheKey()` |
| Request replay | `ReplayPlayer` |
| Distributed runner | `DistributedRunner` |
| Messaging SPI | `MessageValidator`, `InMemoryMessageBus` |
| Report export | `ReportExporter` |
| Conformance fixtures | `ConformanceFixture` |

## Quick example

```java
ApiClient api = Sinaq.emptyClient()
    .baseUrl(wireMock.baseUrl())
    .engine(new JdkHttpEngine())
    .build();

api.get("/health").cacheKey("health-v1").expectStatus(200);

OpenApiValidator validator = new OpenApiValidator(openApiJson);
OpenApiAssertions.expect(api.get("/health").execute(), validator, "/health");

InMemoryMessageBus bus = new InMemoryMessageBus();
bus.publish("orders", "{\"id\":1}");
bus.awaitMessage("orders", Duration.ofSeconds(2),
    MessageExpectation.builder().bodyContains("\"id\":1").build());

ReplayPlayer.replay(api, recorder.exchanges());
String report = ReportExporter.toJson(collectedEvents);
```
