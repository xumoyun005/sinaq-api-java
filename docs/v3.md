# Sinaq API V3 (0.3.0)

V3 focuses on transport diversity, contract testing, recording/HAR export,
database validation, and richer HTTP workflows.

## What's new

| Feature | Package / module |
|---------|------------------|
| OkHttp engine | `sinaq-api-okhttp` |
| Request interceptors | `io.sinaq.api.interceptor` |
| Multipart / file upload | `RequestSpec.multiPart()`, `MultipartBody` |
| GraphQL helpers | `GraphQl.query()`, `request.graphql()` |
| Exchange recording | `ExchangeRecorder`, `RecordedExchange` |
| Contract testing | `ContractVerifier`, `ContractExpectation` |
| HAR export | `HarExporter.toHarJson()` |
| DB validation SPI | `DbValidator`, `sinaq-api-jdbc` |
| Parallel batch | `ParallelBatch.execute()` |

## Quick example

```java
ExchangeRecorder recorder = new ExchangeRecorder();
SinaqRuntime.publisher().register(recorder);

ApiClient api = Sinaq.emptyClient()
    .baseUrl("https://api.example.com")
    .engine(new OkHttpEngine())
    .interceptor(new LoggingInterceptor())
    .build();

api.post("/upload")
   .multiPart("name", "demo")
   .multiPartFile("file", bytes, "doc.pdf")
   .expectStatus(200);

api.post("/graphql").graphql("{ users { id } }").expectStatus(200);

ContractVerifier.verify(recorder.exchanges().get(0),
    ContractExpectation.builder().status(200).build());

String har = HarExporter.toHarJson(recorder.exchanges());

try (JdbcDbValidator db = new JdbcDbValidator("jdbc:h2:mem:test")) {
    new DbAssertions(db).rowCount("SELECT * FROM orders", 1);
}
```
