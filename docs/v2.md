# Sinaq API V2 (0.2.0)

V2 extends the V1 foundation with advanced automation capabilities while keeping
core dependency-free.

## What's new

| Feature | Package / module |
|---------|------------------|
| Full JSONPath | `sinaq-api-jsonpath` (Jayway) |
| JSON Schema validation | `sinaq-api-jsonschema` (NetworkNT) |
| Soft assertions | `response.soft().expect(...).assertAll()` |
| Regex / array assertions | `expectMatches`, `expectArraySize` |
| Request templates | `ApiClient.fromTemplate("name")` |
| Environment profiles | `Sinaq.client(EnvironmentProfile.INT)` |
| OAuth2 + token cache | `sinaq-api-oauth`, `TokenProvider`, `BearerTokenAuth` |
| Polling | `request.poll().until(...).execute()` |
| Test data helpers | `TestData.uniqueId()`, `randomEmail()`, ... |
| Performance metrics | `PERFORMANCE_RECORDED` events |
| Plugin registry | `PluginRegistry.global().register(...)` |
| Parallel requests | `ParallelRequests.executeAll(...)` |
| YAML config | `sinaq-api-yaml` |

## Quick example

```java
ApiClient api = Sinaq.client(EnvironmentProfile.INT)
    .engine(new JdkHttpEngine())
    .plugin(new JaywayExtractionProvider.Plugin())
    .plugin(new NetworkntSchemaValidator.Plugin())
    .registerTemplate(RequestTemplate.builder("createLoan", HttpMethod.POST, "/loan")
        .header("X-App", "1.0")
        .build())
    .build();

api.fromTemplate("createLoan")
   .bearer(new OAuth2TokenProvider(config).accessToken())
   .body(Map.of("amount", TestData.randomDigits(3)))
   .poll()
   .untilStatus(200)
   .execute()
   .soft()
   .expectSchema("{\"type\":\"object\"}")
   .assertAll();
```
